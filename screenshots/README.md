# Екранни снимки — доказателства

Слагайте тук по една снимка на стъпка: `step0.jpg` … `step5.jpg`.
Какво трябва да се вижда на всяка — в раздела „Доказателство“ на съответната стъпка в `ANALYSIS.md`.
Снимката се включва в **същия commit** като кода и анализа на стъпката.

Снимките в тази папка са заснети от реално стартираното приложение. HTTP статусите и URL адресите са записани в `ANALYSIS.md`; те са проверени с HTTP клиент, а не чрез DevTools Network.
