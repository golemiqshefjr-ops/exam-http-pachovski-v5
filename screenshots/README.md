# Екранни снимки — доказателства

Слагайте тук по една снимка на стъпка: `step0.png` … `step5.png`.
Какво трябва да се вижда на всяка — в раздела „Доказателство“ на съответната стъпка в `ANALYSIS.md`.
Снимката се включва в **същия commit** като кода и анализа на стъпката.

Как: DevTools (F12) → Network → Preserve log → изпълнете действието → Win+Shift+S → запазете като PNG тук.
